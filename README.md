Ini adalah website sederhana suit online.
Ketika website disegarkan, maka otomatis random memunculkan gambar jari kelingking, telunjuk, atau ibu jari di player 1 atau player 2.
Flow logika
- buat random angka 1-3
- representasi, jika 1-3 maka berubah menjadi gambar
- kemudian masukan aturan suit, untuk menang dan kalah.
